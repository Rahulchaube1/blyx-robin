# Robin starter

Convert a validated civil date into an ordinal, weekday and comparable day number.

Open the extracted folder in VS Code. With Blyx 0.2.1 and its host toolchain installed, choose **Terminal → Run Task → Run Robin** or run the following command in this directory.

```sh
blyxc native-run main.blyx
```

Expected output

```text
719163
3
1
31
```

The vendor directory contains the framework source for 0.1.0 and its license texts. [Read the API guide](https://www.blyx-lang.space/packages/robin) · [View the release](https://github.com/Rahulchaube1/blyx-robin/releases/tag/v0.1.0)
